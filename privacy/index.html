Politique de confidentialité

Dernière mise à jour : 19 août 2026

1. Responsable du traitement

Peptides Decoded — Publication indépendante (auto-entrepreneur, France).
Contact : via le formulaire de la page d'accueil ou page contact.

2. Données collectées

2.1 Newsletter (opt-in explicite)

  • Adresse email (fourni volontairement via le formulaire d'inscription)
  • Date d'inscription
  • Statut (actif / désinscrit)

Base légale : Consentement (art. 6.1.a RGPD). Le consentement est recueilli par case à cocher non pré-cochée, avec lien vers cette politique.

2.2 Logs techniques (Cloudflare Pages)

  • Adresse IP (anonymisée par Cloudflare — dernier octet masqué)
  • User-Agent, langue navigateur, fuseau horaire
  • Pages visitées, referrer, code de réponse HTTP
  • Date/heure de la requête

Base légale : Intérêt légitime (art. 6.1.f RGPD) — sécurité, performance, détection d'abus.

Rétention : Cloudflare conserve ces logs selon sa politique standard (généralement < 7 jours). Peptides Decoded n'y a pas accès directement.

2.3 Aucunes autres données

  • Pas de Google Analytics, Matomo, Meta Pixel, Hotjar, ou trackers tiers.
  • Pas de cookies publicitaires, de fingerprinting, de localStorage tracking.
  • Pas de formulaire de contact avec stockage (email direct seulement).

4. Partage et destinataires

  • Cloudflare : Hébergement Pages, CDN, WAF, logs (sous-traitant, DPA en place).
  • Fournisseur emailing (si utilisé ultérieurement) : Uniquement pour l'envoi newsletter, contrat DPA, pas d'usage propre des données.
  • Aucune vente, location, cession à des tiers à des fins commerciales.
  • Autorités : Seulement sur réquisition judiciaire valide.

5. Transferts hors UE

Cloudflare Pages utilise un réseau edge global (US, EU, APAC). Les logs techniques peuvent transiter par des serveurs US. Cloudflare est certifié EU-US Data Privacy Framework et propose des clauses contractuelles types (SCC) pour les transferts.

6. Vos droits (RGPD)

Vous disposez des droits suivants :

  • Accès : Obtenir copie de vos données (email via formulaire).
  • Rectification : Corriger email erroné.
  • Effacement : Suppression compte newsletter (équivalent désinscription).
  • Limitation : Gel temporaire du traitement.
  • Portabilité : Recevoir vos données en format structuré (CSV/JSON).
  • Opposition : Au traitement pour intérêt légitime (logs).
  • Retrait consentement : À tout moment via lien "Désinscription" en bas de chaque email.

Exercice : email au responsable (voir §1) ou lien désinscription newsletter. Réponse sous 30 jours.

7. Cookies et traceurs

  • Strictement nécessaires : Aucun (site statique, pas de session).
  • Fonctionnels / Préférences : Aucun.
  • Analytiques / Publicitaires : Aucun.
  • Cloudflare : Peut déposer un cookie __cf_bm (bot management, 30 min, strictement nécessaire sécurité).

Pas de bandeau cookie requis (aucun cookie non essentiel).

8. Sécurité

  • HTTPS forcé (HSTS via Cloudflare).
  • Headers de sécurité : CSP, X-Frame-Options, Referrer-Policy, Permissions-Policy.
  • WAF Cloudflare (règles OWASP, rate limiting).
  • Pas de base de données côté Peptides Decoded (fichiers statiques).

9. Modifications

Toute mise à jour sera publiée sur cette page avec nouvelle date. Changements substantiels notifiés aux abonnés newsletter.

10. Réclamation

Vous pouvez introduire une réclamation auprès de la CNIL (France) : cnil.fr/plainte.
