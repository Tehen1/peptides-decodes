SELECT — Semaglutide 2,4 mg et événements cardiovasculaires majeurs dans l'obésité sans diabète

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

Semaglutide 2,4 mg hebdomadaire réduit de 20 % le risque d'événements cardiovasculaires majeurs (MACE) chez des adultes avec obésité/surpoids et maladie cardiovasculaire athéroscléreuse préexistante, sans diabète de type 2. La perte de poids moyenne de −9,4 % médie partiellement l'effet. Profil de sécurité conforme à la classe GLP-1 (troubles GI). Extension d'indication CV approuvée FDA 2024 (Wegovy).

Type et niveau de preuve

Résultats vérifiés

Critère principal — MACE

  • HR 0,80 [IC95 0,72–0,90] ; p<0,001 — réduction relative 20 %
  • Taux d'événements : 6,5 % (semaglutide) vs 8,0 % (placebo) à 3 ans (Kaplan-Meier)
  • NNT (Number Needed to Treat) : ~67 sur 3 ans pour prévenir 1 MACE
  • Composantes individuelles :

Critères secondaires clés

  • Poids : −9,4 % (semaglutide) vs −0,8 % (placebo) à 104 sem. ; différence −8,6 pp
  • ≥ 5 % perte poids : 67 % vs 10 % ; ≥ 10 % : 43 % vs 4 % ; ≥ 15 % : 22 % vs 1 %
  • Mortalité toutes causes : HR 0,81 [0,66–0,99] — réduction 19 % (limite significativité)
  • Nouveau DT2 : réduction relative 73 % (HR 0,27 [0,19–0,38])
  • HbA1c : −0,4 % vs +0,1 % (diff −0,5 pp)
  • PA systolique : −4,1 mmHg vs −0,8 mmHg
  • CRP haute sensibilité : −39 % vs −8 %

Sécurité

  • AE graves : 27,3 % (semaglutide) vs 30,0 % (placebo) — moins d'AE graves sous traitement
  • AE menant à l'arrêt : 16,6 % vs 8,2 % — principalement GI (nausées, diarrhée, vomissements)
  • Troubles GI : 74 % vs 48 % — majorité légers/modérés, transitoires
  • Pancréatite aiguë : 0,3 % vs 0,2 % (non significatif)
  • Cancer : incidence équilibrée (2,9 % vs 3,0 %) — pas de signal
  • Rétinopathie diabétique : non applicable (population sans DT2)
  • Suicidité (C-SSRS) : pas de signal

Limites

  • Population sélectionnée : ASCVD documentée, sans DT2, IMC ≥27, âge ≥45 — généralisation limitée aux obèses sans maladie CV établie, plus jeunes, ou avec DT2
  • Médiation par perte de poids : analyse de médiation suggère ~50–60 % de l'effet CV médié par perte de poids ; effets directs (inflammation, fonction endothéliale, PA, lipides) plausibles mais non quantifiés de façon définitive
  • Durée 33 mois médian — insuffisante pour mortalité toutes causes (IC95 limite), événements rares, effets très long terme
  • Quasi-exclusion insuffisance rénale sévère (eGFR <30), IC sévère (NYHA IV) — données manquantes chez ces profils à haut risque
  • Ouverture d'étiquette après analyse principale prévue — données extension en cours
  • Financement Novo Nordisk — rôle standard dans design/analyse ; COI déclarés

Réglementation (état août 2026)

  • FDA (mars 2024) : extension d'indication Wegovy (semaglutide 2,4 mg) pour réduction du risque d'événements CV majeurs chez adultes avec obésité/surpoids et ASCVD
  • EMA (juillet 2024) : avis favorable extension Wegovy même indication
  • Registre : NCT03574597 (SELECT)
