Orforglipron (GLP-1 oral) — programme ACHIEVE phase 3 : diabète type 2 et obésité

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

Orforglipron, premier agoniste GLP-1 oral non-peptidique (petite molécule), démontre une efficacité glycémique et pondérale significative dans trois essais de phase 3 (ACHIEVE-1, -5, -J) avec un profil de sécurité dominé par les troubles GI légers à modérés, sans signal d'hépatotoxicité ni d'hypoglycémie sévère. Aucune AMM à ce jour (août 2026).

Résultats vérifiés

ACHIEVE-1 — DT2 régime/exercice seul (n=551, 40 sem.) — NEJM 2025

  • HbA1c : orforglipron 3 mg −1,07 % ; 12 mg −1,35 % ; 36 mg −1,43 % vs placebo −0,21 % (p<0,001 toutes doses)
  • Poids : −2,3 kg (3 mg) ; −3,6 kg (12 mg) ; −4,2 kg (36 mg) vs +0,3 kg placebo
  • HbA1c < 7 % : 59 % (3 mg) ; 73 % (12 mg) ; 77 % (36 mg) vs 14 % placebo
  • Population : 551 randomisés, HbA1c moyen 8,1 %, IMC moyen 29,3, 52 % femmes, multiethnique

ACHIEVE-5 — DT2 sur insuline basale titrée ± metformine/iSGLT2 (n=546, 40 sem.) — JAMA 2026

  • HbA1c : orforglipron 3 mg −1,58 % ; 12 mg −1,88 % ; 36 mg −1,82 % vs placebo −0,79 % (diff −0,78 ; −1,08 ; −1,03 pp, p<0,001)
  • Poids : −2,6 % (3 mg) ; −4,8 % (12 mg) ; −5,4 % (36 mg) vs +0,2 % placebo
  • HbA1c < 7 % : 54 % (3 mg) ; 67 % (12 mg) ; 65 % (36 mg) vs 28 % placebo
  • Hypoglycémie cliniquement significative (niveau 2) : 2–3 % orforglipron vs 3 % placebo — pas d'augmentation
  • Population : 546 randomisés, HbA1c moyen 8,5 %, IMC moyen 30,8, durée DT2 médiane 14,6 ans

ACHIEVE-J — Japon, DT2 régime/exercice ou 1–2 ADO (n=401, 52 sem.) — Lancet Diabetes Endocrinol 2026

  • Design : ouvert, 3 bras (3 mg, 12 mg, 36 mg), critère principal = sécurité 52 sem.
  • AE ≥ 1 : 81 % (3 mg) ; 84 % (12 mg) ; 88 % (36 mg) — principalement GI
  • Arrêts pour AE : 5 % (3 mg) ; 8 % (12 mg) ; 14 % (36 mg) — dose-dépendant
  • Hypoglycémie niveau 2 : 2 % (12 mg) ; 2 % (36 mg) ; 0 % (3 mg) — pas de niveau 3 (sévère)
  • Conclusion : profil de sécurité acceptable sur 52 sem. chez adultes japonais

Analyse pooled hépatique — 7 essais phase 3 (n=11 220) — Diabetes Obes Metab 2026

  • ALT/AST : réductions moyennes sous orforglipron ; élévations catégorielles (≥3×ULN) équilibrées vs comparateurs (0,1 % chaque bras)
  • Loi de Hy / DILI : 6 cas (0,1 %) orforglipron avec ALT/AST ≥3×ULN + TBIL ≥2×ULN — tous expliqués par étiologies alternatives, aucun ne remplit critères DILI/Hy's Law
  • AE hépatiques : incidence équilibrée orforglipron vs comparateurs
  • Sous-groupes (ALT/AST élevés à l'inclusion) : résultats cohérents
  • Interprétation : profil hépatique cohérent avec bénéfices métaboliques de la perte de poids, pas de signal d'hépatotoxicité

Sécurité globale (ensemble programme)

  • Effets indésirables dominants : nausées, vomissements, diarrhée, constipation — dose-dépendants, majoritairement légers à modérés, survenant tôt, souvent transitoires
  • Hypoglycémie : pas d'augmentation vs placebo, y compris en ajout à insuline basale (ACHIEVE-5)
  • Pancréatite, tumeurs thyroïdiennes : aucun signal nouveau vs classe GLP-1
  • Hépatique : rassurant (voir analyse pooled ci-dessus)

Limites

  • Population DT2 uniquement — essais obésité sans DT2 en cours (ACHIEVE-2, -3, -4), résultats non publiés
  • Durée 40–52 semaines — insuffisante pour événements cardiovasculaires (MACE), rénaux, oncologiques à long terme
  • ACHIEVE-J ouvert (non en aveugle) — biais possible sur évaluation subjective des AE
  • Comparateur placebo dans ACHIEVE-1 et -5 — pas de comparaison directe vs GLP-1 injectables (semaglutide, tirzépatide) ni vs orforglipron vs semaglutide oral
  • Population ACHIEVE-J exclusivement japonaise — généralisation limitée aux autres ethnies asiatiques
  • Financement exclusif Eli Lilly — rôle dans design, analyse, rédaction ; COI étendus déclarés (employés/actionnaires parmi auteurs)
  • Effet dose-dépendant sur arrêts pour AE (jusqu'à 14 % à 36 mg) — dose optimale efficacité/tolérance à définir

Réglementation (état août 2026)

  • Statut : médicament expérimental — aucune AMM (FDA, EMA, PMDA Japon, autres) à ce jour
  • Développement : programme ACHIEVE phase 3 principal achevé ; dossiers réglementaires en préparation
  • Registres : NCT05513266 (ACHIEVE-1), NCT06109311 (ACHIEVE-5), NCT06010004 (ACHIEVE-J)
