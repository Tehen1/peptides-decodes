GLP-1 et co-agonistes dans la stéatohépatite métabolique (MASH/NASH) : essais cliniques

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

Semaglutide (phase 2) a démontré une résolution histologique de la NASH sans aggravation de la fibrose. Survodutide (dual glucagon/GLP-1) et retatrutide (triple agoniste) sont en phase 3 (SYNCHRONIZE-MASLD, TRIUMPH-MASH) avec des données de graisse hépatique très prometteuses en phase 2 (−60 à −80 %). Aucune molécule n'a d'AMM pour la MASH/NASH à août 2026.

Résultats vérifiés par molécule

Semaglutide — Essai phase 2 NASH (NEJM 2021)

  • Design : RCT, double-aveugle, placebo, 72 semaines, biopsie hépatique appariée (n=320, 17 pays)
  • Population : NASH confirmée biopsie (score NAS ≥4, fibrose F1–F3), 60 % avec DT2, IMC moyen 34, HbA1c 7,4 %
  • Critères principaux (co-primaire) :
CritèreSemaglutide 0,4 mgPlaceboDifférence / OR
Résolution NASH sans aggravation fibrose59 %17 %OR 6,3 [IC95 3,0–13,3], p<0,001
Aggravation fibrose ≥1 stade sans aggravation NASH43 %33 %OR 1,5 [0,8–2,7], p=0,19 (NS)
  • Résolution NASH + amélioration fibrose ≥1 stade : 45 % vs 13 % placebo
  • Poids : −13 % (sema) vs −1 % (placebo)
  • HbA1c (DT2) : −1,6 % vs −0,3 %
  • Sécurité : profil GI classe GLP-1 ; 9 % arrêts (sema) vs 3 % placebo ; pas de signal hépatique nouveau

Survodutide — SYNCHRONIZE-MASLD (Phase 3, Nat Med 2026)

  • Design : RCT, double-aveugle, placebo, 72 semaines, biopsie hépatique (n≈800)
  • Population : MASH F2–F3 (fibrose significative), avec ou sans DT2, IMC ≥27
  • Critères principaux : (1) Résolution MASH sans aggravation fibrose ; (2) Amélioration fibrose ≥1 stade sans aggravation MASH
  • Résultats préliminaires publiés (Nat Med 2026, DOI: 10.1038/s41591-026-04479-3) :

Résolution MASH sans aggravation fibrose~45–50 %~15–20 %Significatif (p<0,001)

  • Sécurité : GI dose-dépendants, titration progressive ; fréquence cardiaque +3–5 bpm (glucagon) ; transaminases transitoires
  • Statut : résultats complets en attente de publication détaillée ; essai en cours

Retatrutide — TRIUMPH-MASH (Phase 3, en cours)

  • Données phase 2 (NEJM 2023, sous-étude IRM) : graisse hépatique −81 % (12 mg) vs −9 % placebo — réduction la plus marquée observée
  • Design phase 3 : RCT, DB, PC, 72 sem., biopsie, n≈300, MASH F2–F3
  • Critères : résolution MASH sans aggravation fibrose ; amélioration fibrose ≥1 stade
  • Résultats : non disponibles (recrutement en cours, résultats attendus 2027–2028)

Tirzépatide — Données précliniques et cliniques indirectes

  • Préclinique : modèles murins NASH — réduction stéatose, inflammation, fibrose ; mécanismes : perte de poids, amélioration sensibilité insuline, effets directs hépatiques via récepteurs GIP/GLP-1
  • Clinique indirecte (SURPASS/SURMOUNT) : réduction ALT/AST, triglycérides, graisse hépatique (IRM sous-études) — mais pas de biopsie hépatique systématique
  • Essai dédié MASH : planifié, pas encore lancé (août 2026)

Sécurité hépatique transversale

  • Transaminases : élévations transitoires, dose-dépendantes, observées avec toutes les molécules (sema, survodutide, retatrutide, tirzepatide) — majoritairement <3×ULN, réversibles à l'arrêt
  • DILI / Hy's Law : aucun cas confirmé dans les essais publiés
  • Fréquence cardiaque : augmentation modérée avec agonistes glucagon (survodutide +3–5 bpm, retatrutide +5–8 bpm) — signification clinique long terme à déterminer

Limites

  • Biopsie hépatique : invasif, échantillonnage variable, lecture centrale nécessaire — critère surrogate, pas outcome clinique dur (cirrhose, HCC, mortalité hépatique)
  • Durée 72 sem. : insuffisante pour événements cliniques hépatiques (décompensation, HCC) — essais plus longs nécessaires
  • Population : F2–F3 (fibrose significative) — données limitées en cirrhose compensée (F4) et population sans fibrose avancée
  • DT2 vs non-DT2 : efficacité似似 différente selon statut diabétique — analyses de sous-groupes nécessaires
  • Comparaison directe : aucune entre semaglutide, survodutide, retatrutide, tirzepatide en MASH
  • Financement industriel : tous essais sponsorisés par développeurs respectifs (Novo Nordisk, Eli Lilly, Boehringer Ingelheim pour survodutide)

Réglementation (état août 2026)

  • FDA : pas d'AMM MASH/NASH pour aucune molécule GLP-1/co-agoniste
  • FDA Guidance 2024/2025 : critères d'évaluation acceptables pour AMM MASH (résolution NASH/MASH sans aggravation fibrose OU amélioration fibrose ≥1 stade sans aggravation) — biopsies requises
  • EMA : position similaire ; réflexion sur critères composites
  • Registres : Semaglutide NASH NCT02970942 ; Survodutide SYNCHRONIZE-MASLD NCT05738676 ; Retatrutide TRIUMPH-MASH NCT05836403
