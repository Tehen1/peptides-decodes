CagriSema (cagrilintide + semaglutide) — programme REIMAGINE phase 3 : diabète type 2 et obésité

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

CagriSema (cagrilintide 2,4 mg + semaglutide 2,4 mg) démontre une supériorité cliniquement significative sur l'HbA1c et le poids versus semaglutide seul et versus placebo dans trois essais de phase 3 (REIMAGINE 1, 2, 3). Le profil de sécurité reste celui de la classe GLP-1 (troubles GI). Aucune approbation réglementaire à ce jour.

Résultats vérifiés

REIMAGINE 2 — DT2 sur metformine ± iSGLT2 (n=2713, 68 sem.) — Lancet Diabetes Endocrinol 2026

  • Critère principal HbA1c : CagriSema 2,4/2,4 mg −1,91 % vs semaglutide 2,4 mg −1,75 % ; différence −0,16 pp [IC95 −0,27 à −0,05], p=0,0035 (supériorité confirmée)
  • Poids : CagriSema 2,4/2,4 mg −10,4 % vs semaglutide 2,4 mg −7,4 % ; cagrilintide 2,4 mg −4,4 %
  • HbA1c < 7 % : 72 % (CagriSema 2,4/2,4) vs 58 % (sema 2,4) vs 28 % (cagrilintide)
  • Population : 2713 randomisés, 81 % Blancs, 43 % femmes, HbA1c moyen 8,2 %, IMC moyen ~33

REIMAGINE 1 — DT2 régime/exercice seul (n=597, 68 sem.) — Lancet Diabetes Endocrinol 2026

  • HbA1c : CagriSema 2,4/2,4 mg −2,08 % vs placebo −0,39 % ; CagriSema 1,0/1,0 mg −1,77 % vs placebo −0,39 % (supériorité p<0,0001)
  • Poids : −7,2 kg (2,4/2,4) vs −1,1 kg placebo ; −5,8 kg (1,0/1,0) vs −1,1 kg placebo
  • HbA1c < 6,5 % : 61 % (2,4/2,4) vs 8 % placebo ; 48 % (1,0/1,0) vs 8 % placebo

REIMAGINE 3 — DT2 sur insuline basale ± metformine (n=274, 40 sem.) — Lancet 2026

  • HbA1c : CagriSema 2,4/2,4 mg −2,33 % vs placebo −0,66 % (diff −1,68 pp [−1,95 ; −1,41], p<0,0001)
  • Poids : −10 à −12 % (doses 2,4/2,4 et 1,0/1,0) vs ~0 % placebo
  • Hypoglycémie sévère : 0 cas dans les bras CagriSema
  • Dose d'insuline : réduction significative vs placebo

Sécurité (ensemble des 3 essais)

  • Effets indésirables dominants : troubles gastro-intestinaux (nausées, vomissements, diarrhée, constipation) — dose-dépendants, majoritairement légers à modérés
  • Taux d'AE : ~80–88 % (CagriSema 2,4/2,4) vs ~71–81 % (semaglutide) vs ~70–71 % (placebo)
  • Arrêts pour AE : 6–14 % (dose 2,4/2,4) vs 4–8 % (dose 1,0/1,0) vs 3–5 % (placebo) — principalement GI
  • Hypoglycémie sévère : nulle (REIMAGINE 3), rare (autres essais)
  • Pancréatite, tumeurs thyroïdiennes : aucun signal nouveau vs classe GLP-1
  • Un décès (REIMAGINE 3) : néoplasie maligne, non lié au traitement selon investigateurs

Limites

  • Population DT2 uniquement — pas de données obésité sans DT2 dans REIMAGINE (essai distinct prévu : NCT07357766, RETIRÉ pour raisons stratégiques)
  • Durée 40–68 semaines — insuffisante pour événements cardiovasculaires, oncologiques, rénaux à long terme
  • Comparateur semaglutide 2,4 mg (dose DT2) dans REIMAGINE 2 — pas de comparaison directe vs semaglutide 2,4 mg (dose obésité, STEP)
  • Quasi-totalité des patients Blancs (81 %) — généralisation limitée aux autres ethnies
  • Financement exclusif Novo Nordisk — rôle dans design, analyse, rédaction ; COI étendus déclarés
  • Pas de bras actif vs tirzépatide dans ces 3 essais (REIMAGINE 5 en cours, NCT06534411, COMPLÉTÉ juin 2026, résultats non publiés)

Réglementation (état août 2026)

  • Statut : médicament expérimental — aucune AMM (FDA, EMA, autres) à ce jour
  • Développement : programme REIMAGINE phase 3 achevé (résultats publiés juin 2026) ; dossier réglementaire en préparation
  • Registres : NCT06323174 (REIMAGINE 1), NCT06065540 (REIMAGINE 2), NCT06323161 (REIMAGINE 3)
