Peptide-drug conjugates (PDC) et vaccins peptidiques en oncologie — panorama

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

Les conjugués peptide-médicament radiopharmaceutiques (PDC) ont abouti à une première AMM (Lu-177-PSMA-617 / Pluvicto, mCRPC 2022). Les PDC ciblant FAP (FAP-2286) et les vaccins peptidiques néoadjuvants/adjuvants (néo-antigènes mRNA-4157/V940, TG4050, ELI-002) sont en essais cliniques avancés. Aucun vaccin peptidique n'a d'AMM à août 2026. Le domaine évolue vite : ciblage tumoral, charge cytotoxique/radioisotope, présentation antigénique personnalisée.

Conjugués peptide-médicament (PDC) radiopharmaceutiques

Lu-177-PSMA-617 (Pluvicto) — PSMA — AMM mCRPC 2022

  • Mécanisme : peptide PSMA-617 (cible PSMA sur cellules prostatiques) chélaté au Lu-177 (émetteur β⁻, γ) — radiothérapie interne vectorisée
  • Essai VISION (phase 3, NCT03511664) : 831 patients mCRPC post-ARPI + taxane, Lu-177-PSMA-617 + BSC vs BSC seul
  • Résultats principaux :

  • Sécurité : xerostomie (39 % gr 1–2), fatigue (43 %), thrombopénie (13 % gr 3–4), anémie, nausées ; rares : syndrome myélodysplasique/leucémie aiguë (~1 %)
  • AMM : FDA mars 2022, EMA décembre 2022 — mCRPC PSMA-positif post-ARPI + chimiothérapie

FAP-2286 (Lu-177) — FAP (fibroblastes d'activation protéase) — Phase 1/2

  • Cible : FAP — exprimé par fibroblastes associés au cancer (CAF) dans stroma tumoral (carcinomes pancréas, colorectal, sein, poumon, sarcomes) — pan-tumoral
  • Design : peptide cyclique FAP-2286 radiomarqué Lu-177 (thérapeutique) ou Ga-68 (diagnostique — PET imaging)
  • Essai phase 1 (NCT05182051, Lancet Oncol 2024) : 80 patients tumeurs solides avancées FAP-positives (PET Ga-68-FAP-2286)
  • Résultats préliminaires : DCR (disease control rate) ~60–70 % ; réponses partielles observées (pancréas, colorectal, sarcomes) ; sécurité : thrombopénie dose-limitante, fatigue, nausées, xerostomie
  • Particularité : ciblage stromal (non tumoral direct) — potentiel large spectre tumeurs solides
  • Statut : phase 2 en cours, extensions combinaisons (immunothérapie, chimiothérapie)

Autres PDC radiopharmaceutiques / cytotoxiques notables

  • Camidanlumab tesirine (ADCT-301) : ADC anti-CD25 (lymphome hodgkinien, CTCL) — phase 2, activité signalée
  • Lu-177-DOTATATE (Lutathera) : somatostatine analog (SSTR2) — AMM 2018 tumeurs neuroendocrines GEP-NET — précurseur PDC peptide
  • Ac-225-PSMA-617 : alpha-émetteur (plus haute LET) — essais phase 1/2 post-échec Lu-177, toxicité xerostomie accrue

Vaccins peptidiques anticancéreux

mRNA-4157 / V940 (Moderna/MSD) — Néo-antigènes personnalisés + pembrolizumab

  • Approche : séquençage tumeur/germline → identification mutations → sélection néo-antigènes (jusqu'à 34) → ARNm encapsulé LNP → injection IM + anti-PD-1 (pembrolizumab)
  • Phase 2b KEYNOTE-942 (mélanome stade III/IV réséqué, n=157) : mRNA-4157 + pembro vs pembro seul
  • Résultats (ASCO 2023, NEJM 2024) : RFS (sans récidive) HR 0,56 [0,31–0,99], p=0,045 — réduction 44 % risque récidive/mort
  • Phase 3 KEYNOTE-A21/INTerpath-003 (NCT05933577) : en cours, n≈1 000, mélanome stade II–IV réséqué
  • Autres tumeurs : essais en cours NSCLC (KEYNOTE-603), vessie, colorectal
  • Sécurité : ajout mRNA bien toléré ; AE liées 주로 à pembrolizumab (thyroïdites, hépatites, colitis)

TG4050 (Transgene) — Néo-antigènes personnalisés (vecteur viral MVA)

  • Approche : vecteur Modified Vaccinia Ankara (MVA) encodant néo-antigènes personnalisés (jusqu'à 30) — injection SC
  • Essais : Phase 1/2 oviaire (NCT04183166), tête-cou (NCT04183166), SARCOME (NCT05349817)
  • Résultats préliminaires : immunogénicité (réponses T CD8+ spécifiques néo-antigènes détectées), sécurité acceptable, signaux d'efficacité clinique (stabilisation, réponses partielles anecdotiques)
  • Différenciation : vecteur viral vs ARNm — immunité innée activée différemment

ELI-002 (Elicio Therapeutics) — Peptides KRAS G12D/G12R + adjuvant AMP-CpG (lymph node targeting)

  • Cible : mutations KRAS partagées (G12D, G12R) — pancréas, colorectal, poumon
  • Technologie : amphiphile (AMP) ciblant ganglions lymphatiques + CpG (TLR9 agonist) — forte immunogénicité
  • Phase 1/2 (AMPLIFY-201, NCT04853017) : PDAC réséqué, colorectal — réponse T cellules détectable, clairance ctDNA chez certains patients
  • Phase 2 (AMPLIFY-701) : en cours, PDAC adjuvant

Autres vaccins peptidiques notables

  • PVX-410 (multi-peptide, myélome multiple) : phase 1/2, peptides XBP1, CD138, CS1 — en combinaison lenalidomide
  • SurVaxM (survivine peptide) : glioblastome — phase 2, résultats mitigés
  • Vaccins « off-the-shelf » peptides partagés (p53, hTERT, HER2, MUC1) : historiques, efficacité limitée seule — pivot vers néo-antigènes personnalisés + checkpoint inhibitors

Limites transversales

  • PDC : toxicités hématologiques (médullaires) dose-limitantes ; xérostomie (PSMA/FAP) ; coûts/logistique radiopharmaceutiques (radioprotection, chaîne froid, sites autorisés) ; résistance (perte cible, réparation ADN) ; pas de PDC cytotoxique peptide AMM à ce jour
  • Vaccins néo-antigènes : délai fabrication (4–8 sem. ARNm, plus long viral) — inadapté maladie très agressive ; coût élevé (personnalisation) ; HLA-restriction (présentation limitée) ; évasion immunitaire (perte néo-antigène, MHC downregulation) ; combinaison ICB quasi-systématique requise
  • Biomarqueurs : ctDNA (clairance), réponses T spécifiques (tetramers, ELISpot), PET cible (PSMA, FAP) — non standardisés, non validés comme surrogates
  • Comparaisons directes : aucune entre PDC radio, PDC cytotoxique, vaccins ARNm, vaccins viraux, vaccins peptides partagés

Réglementation (état août 2026)

  • AMM PDC : Lu-177-PSMA-617 (Pluvicto) mCRPC ; Lu-177-DOTATATE (Lutathera) GEP-NET — seuls 2 PDC peptide AMM
  • AMM vaccins peptidiques : aucune à août 2026
  • FDA : RMAT (Regenerative Medicine Advanced Therapy) pour mRNA-4157/V940 ; Fast Track plusieurs PDC/vaccins
  • EMA : PRIME (PRIority MEdicines) pour plusieurs candidats
  • Registres clés : VISION NCT03511664 ; FAP-2286 NCT05182051 ; KEYNOTE-942 NCT03897881 ; KEYNOTE-A21 NCT05933577 ; TG4050 NCT04183166 ; ELI-002 NCT04853017
