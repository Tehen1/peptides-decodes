GHK-Cu (peptide de cuivre) — régénération cutanée, cicatrisation, anti-âge : preuves cliniques

Publié le 20 août 2026 · Dernière vérification : 20 août 2026

Verdict

GHK-Cu (glycyl-L-histidyl-L-lysine-Cu²⁺) est un peptide endogène à forte affinité pour le cuivre, avec des mécanismes moléculaires robustement documentés in vitro (stimulation collagène/GAG, inhibition MMP/inflammation, chélation cuivre redox). Les données cliniques restent limitées : essais de petite taille (n=10–41), courte durée (4–12 semaines), souvent ouverts ou sans groupe témoin robuste. La pénétration cutanée est le défi majeur. Statut : ingrédient cosmétique (CIR safe ≤0,1 %), non médicament.

Mécanismes moléculaires (préclinique — données robustes)

  • Stimulation matrice extracellulaire : upregulation collagène I, III, IV ; glycosaminoglycanes (GAG) ; decorine ; fibronectine ; intégrines — fibroblasts humains, peau ex vivo
  • Inhibition dégradation : downregulation MMP-1, -2, -9 ; upregulation TIMP-1, -2
  • Anti-inflammatoire : inhibition TNF-α, IL-1β, IL-6, NF-κB, COX-2 ; réduction ROS, stress oxydatif
  • Chélation cuivre : GHK lie Cu²⁺ (Kd ~10⁻¹⁶ M) — transporte cuivre biodisponible, prévient Fenton/Haber-Weiss, module enzymes Cu-dépendantes (LOX, SOD)
  • Expression génique : transcriptome (Broad Institute Connectivity Map) — GHK inverse ~70 % gènes marqueurs vieillissement cutané ; pathways : TGF-β, Wnt, intégrines, réponse au stress
  • Cicatrisation : angiogenèse (VEGF), recrutement macrophages, réépithélialisation — modèles murins excision/brûlure

Cicatrisation post-procédure (laser, peelings)

  • Post-laser CO2 fractionné / Erbium : plusieurs petites séries (n=10–15) — application topique GHK-Cu accélère réépithélialisation (3–5 j vs 5–7 j témoin historique), réduit érythème, œdème, croûtes
  • Post-peeling TCA / phénol : données anecdotiques / cas cliniques — cicatrisation plus rapide, moins de complications pigmentaires
  • Mécanisme proposé : modulation inflammation (TNF-α, IL-1↓), stimulation kératinocytes, angiogenèse locale

Barrière cutanée et hydratation

  • Études ex vivo / in vivo (n=15–20) : GHK-Cu améliore TEWL, céramides, filagrine, loricrine — suggère renforcement barrière
  • Synergie rapportée avec céramides, acide hyaluronique, niacinamide

Pénétration cutanée — défi majeur

  • Franz diffusion (peau humaine/ex vivo) : GHK-Cu libre : pénétration <1 % dose appliquée dans derme viable ; retention stratum corneum majoritaire
  • Vecteurs améliorant pénétration : liposomes (2–5×), nanoliposomes, microneedles (patchs), émulsions nano-structurées, iontophorèse
  • Conséquence : résultats cliniques très dépendants du véhicule — crème/sérum standard = biodisponibilité dermique faible

Sécurité

  • CIR Expert Panel 2021 (Copper Tripeptide-1) : conclusion « safe in cosmetics » aux concentrations ≤0,1 % — données insuffisantes pour >0,1 %
  • Irritation / sensibilisation : faible à concentrations cosmétiques ; tests HRIPT (Human Repeat Insult Patch Test) négatifs à 0,1 %
  • Toxicité systémique : non évaluée cliniquement ; absorption systémique attendue négligeable à usage cosmétique (faible pénétration)
  • Cuivre libre : risque théorique stress oxydatif si GHK saturé — non observé in vitro à doses physiologiques ; GHK chélate Cu redox-actif
  • Grossesse / allaitement : pas de données — prudence recommandée

Limites

  • Preuves cliniques minces : <10 essais publiés, n totaux <150, durées ≤12 sem, majorité ouverts ou vs véhicule seul, pas de RCT vs rétinoïdes/vitamine C/peptides de référence
  • Pénétration : limite fondamentale — efficacité dermique dépendante du véhicule, peu standardisée entre produits commerciaux
  • Dose-réponse : non établie cliniquement ; concentrations commerciales variables (0,01–0,1 % typique, parfois non déclarées)
  • Stabilité : GHK-Cu sensible pH, lumière, oxydation — formulations complexes requises
  • Biomarqueurs : pas de biomarqueur validé de réponse clinique (collagène sérique, imagerie) dans essais cosmétiques
  • Comparaison actifs de référence : aucune RCT vs trétinoïne, vitamine C, bakuchiol, peptides anti-âge établis (Matrixyl, etc.)
  • Financement : majorité études historiques liées à inventeur (Pickart) ou fournisseurs matière première — biais potentiel

Réglementation (état août 2026)

  • USA (FDA) : ingrédient cosmétique (INCI Copper Tripeptide-1) — pas de NDA/ANDA ; warning letters occasionnelles pour claims « drug-like » (anti-rides « cliniquement prouvé », cicatrisation « médicale »)
  • UE (Règlement 1223/2009) : ingrédient cosmétique autorisé — concentration ≤0,1 % recommandée (CIR) ; pas de restriction annexes
  • CIR (Cosmetic Ingredient Review) 2021 : safe ≤0,1 % ; données insuffisantes >0,1 %
  • Claims autorisés cosmétiques : « améliore l'apparence des rides », « hydrate », « soutient la barrière cutanée » — interdits : « stimule la production de collagène », « répare l'ADN », « cicatrise », « traitement »
